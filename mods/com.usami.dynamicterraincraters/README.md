# Dynamic Terrain Craters

[简体中文](README.zh-CN.md) · English

The Hawkstore sample subscription package for Ravenfield EA38 and BepInEx 5. It adds configurable runtime terrain craters, soft scorch marks, distant crater overlays, and vegetation clearing.

Install it from the Hawkstore **Store** page. Hawkstore verifies the release SHA-256, backs up an existing installation, and preserves whether the plugin was enabled or disabled.

Version: `1.9.0`

Plugin GUID: `com.usami.dynamicterraincraters`
